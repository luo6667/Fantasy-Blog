# 2026-11-23

## 博客图片加载优化（P0 存量迁移）

**背景**：博客正文图片走 `dangerouslySetInnerHTML` 原生 `<img>`，绕开 next/image；后端上传接口已有 WebP 优化（commit 5ef2e65e，11-22 19:15 上线），但存量图未迁移。实测本地 `uploads/` 有 1917×1078、1.98MB 的 PNG，页面最大只显示 860px。

**关键结论**：新上传的图确实转 WebP（线上 API 验证：11-23 21:33 传的图是 `?optimized=1&w=1600&h=888` 带 srcset）；存量图全是裸 PNG/JPG。`enhanceImage()` 靠 `?optimized=1` 判断是否注入 srcset，所以只转文件不改 URL 等于白做。

**本次改动**：
- 新增 `blog-server/internal/imgproc/`：把转码逻辑从 `handlers_upload.go` 抽成公共包（MasterWidth=1600、Quality=82、变体 480/960），上传接口与迁移脚本共用，避免参数漂移。
- 新增 `blog-server/cmd/imgmigrate/`：扫描 `articles.content`，转 WebP + 改写 URL + 重渲染 `contentHtml`。默认 dry-run，`-apply` 才执行，自动备份 JSON，支持 `-restore` 回滚。
- `go.mod`：`gen2brain/webp`、`golang.org/x/image` 从 indirect 修正为直接依赖。

**实测**：1982 KB → 100 KB（1922×915 → 1600×899），纯 Go 编码器（CGO_ENABLED=0，与生产一致）。

**待办**：存量迁移还没在服务器上跑；`deploy/nginx-blog.conf.example` 的 `/uploads/` 仍走 Next rewrite（三跳），建议改 `alias` 直出。
